# EasyComic

一款基于 Electron + React + TypeScript 的本地漫画阅读器。

## 功能特性

- 支持 PDF、EPUB、ZIP / RAR / CBZ / CBR 等常见漫画格式
- 支持单页、双页、连续条漫等多种阅读模式
- 本地书架与最近阅读记录
- 简洁的中文界面
